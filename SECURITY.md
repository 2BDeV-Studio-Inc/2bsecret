# Biztonsági irányelvek

## Támogatott verziók

Az alábbi verziók kapnak jelenleg biztonsági frissítéseket:

| Verzió                    | Támogatott |
| ------------------------- | ---------- |
| 0.4.0                     | ✅         |
| 0.3.0                     | ❌         |
| Python alapú alkalmazás   | ❌         |

## Sérülékenység jelentése

Ha biztonsági hibát találsz, **kérjük, ne nyiss nyilvános issue-t.**

Helyette jelentsd privát módon az alábbi lehetőségek egyikén:

- **Email:** info@2bdevon.top
- **GitHub privát advisory:** https://github.com/2BDeV-Studio-Inc/2bsecret/security/advisories/new

### Mit tartalmazzon a jelentés

- A sérülékenység rövid leírása
- A reprodukálás lépései
- Várható hatás vagy érintett verziók
- Javasolt javítás (opcionális, de hasznos)

### Válaszidő

- **Visszaigazolás:** 48 órán belül
- **Állapotfrissítés:** 7 napon belül
- **Javítás vagy megoldás:** 30 napon belül (súlyosságtól függően)

Ha a hibát elfogadjuk, megemlítünk a release jegyzetekben (ha szeretnéd, név nélkül is).  
Ha elutasítjuk, megindokoljuk a döntést.

Köszönjük, hogy segítesz biztonságban tartani a projektet.

# Security Guidelines

## Supported Versions

The following versions currently receive security updates:

| Version                   | Supported  |
| ------------------------- | ---------- |
| 0.4.0                     | ✅         |
| 0.3.0                     | ❌         |
| Python-based application  | ❌         |

## Vulnerability Reporting

If you find a security bug, **please do not open a public issue.**

Instead, report it privately through one of the following options:

- **Email:** info@2bdevon.top
- **GitHub private advisory:** https://github.com/2BDeV-Studio-Inc/2bsecret/security/advisories/new

### What the report should include

- A brief description of the vulnerability
- Steps to reproduce it
- Expected impact or affected versions
- Suggested fix (optional but helpful)

### Response Times

- **Acknowledgement:** within 48 hours
- **Status update:** within 7 days
- **Fix or solution:** within 30 days (depending on severity)
